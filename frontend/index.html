#game-factory

Build playable games by chatting

K Games is a chatbot with a team of agents behind it. Describe a game, confirm the design, and it builds, tests and hands you a game you can play, download or install as an app.

Arcade hits, brain teasers, or something only you would think of

Start from a template prompt, or describe your own from scratch.

Use the arcade template

      See every step of every build

      A build runs as a tracked plan. Each step shows up live as it starts, finishes, retries or is skipped, so you never stare at a spinner wondering what is going on.

      Every step, live

      The progress card lists the whole plan with what's done, running and left, built from real milestones like controls, scoring and audio.

      Fixes its own mistakes

      Code that fails to compile or imports a missing file goes back to the builder for repair, up to twice, before you ever see it.

      QA before you play

      A review pass mentally tests logic, controls, win and lose, and restart, and can patch just the files that need it.

      A real project, not a single file

      Every game is an organized project of plain ES modules. Ask for a change and only the files it touches are rewritten; everything else carries over.

        one file

        Say “just a one-file prototype” and you get a single self-contained index.html.

        multi-file

        The default: components, scenes, game logic and docs, each in the same folder every time.

        versioned

        Every build and improvement is saved as a new version, so nothing you liked is ever lost.

        Play your first game in a few minutes

        Describe it in a sentence, answer only the questions that matter, and it opens in a new tab ready to play.

        Asks only what's missing

        The designer never invents mechanics you didn't ask for.

        You confirm the design

        Nothing is built until you say yes to the design summary.
